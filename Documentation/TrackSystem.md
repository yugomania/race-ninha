# Animal Combat Racing — Track System Specification

## 1. Modular Components
* **Start Grid**: Array of transform spawn nodes (Pole position, P2, P3, P4).
* **Centerline Spline**: Smooth mathematical path used for AI navigation and distance calculations.
* **Checkpoint Sequence**: Ordered trigger volumes for lap and anti-cheat validation.
* **Mystery Ball Spawners**: Floating power-up pickup clusters.
* **Finish Line Gate**: Lap increment trigger with checkered banner.
